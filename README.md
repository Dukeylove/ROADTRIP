# Dukey’s Roadtrip (GitHub Pages)

**Für Anfänger – kein manuelles Bauen nötig.**  
Einfach dieses Repo auf GitHub pushen. Der Deploy läuft automatisch und setzt die richtige Base-URL.

## So machst du’s
1. Geh zu GitHub und erstelle ein neues Repository, z. B. `dukeys-roadtrip`.
2. Lade **ALLE Dateien** aus diesem Ordner ins Repo hoch.
3. Warte, bis der grüne Haken erscheint (Actions bauen automatisch).
4. Deine Seite: `https://<dein-user>.github.io/<dein-repo>/`

## Lokal starten (optional)
```bash
npm install
npm run dev
```
